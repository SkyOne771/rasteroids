# Project attribution

Rasteroids Web is a portfolio extension of the [Rasteroids workshop game](https://github.com/Akkowicz/rasteroids) by Akkowicz and its contributors. The fork retains the original repository history and monochrome Asteroids-inspired game design.

This web edition adds the Python/SQLite account and score backend, authentication and persistent sessions, public and personal scoreboards, multi-touch mobile input, responsive play layouts, regression and browser tests, and the OVH deployment and documentation automation.

The upstream repository did not provide an explicit software license when this edition was prepared.
